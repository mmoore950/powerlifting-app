# Local reference manifest

`video-evaluation.schema.json` declares JSON Schema2020-12 structure. `video-fixture-manifest.json` deliberately contains zero clips/observations. No real video or annotation has been invented. Clip paths are relative to a private local asset root, not URLs to upload; keep media and populated private manifests in ignored artifacts. Store authorization/license evidence locally and avoid personal names in source-group IDs.

For each real clip record content hash, source group, permission evidence, lift, target identity, upright display dimensions, partition and frame annotations. Preserve actual CMTime presentation value/timescale/epoch, with Int64 value as a decimal string so JSON does not round it. Do not derive time from nominal frame rate; VFR and discontinuities matter. Visible annotations require an upright normalized point and reference uncertainty in display pixels. Occlusion/outside-frame/uncertain states can have no point. Reference uncertainty is annotation uncertainty, not a detector confidence score.

Keep repeated exports/crops from the same recording/subject group in one split, and hash-identical media in one split. Tune only on development/training; do not tune against held-out clips and then call them independent accuracy evidence. Synthetic reference provenance is separate from manually observed real reference. Detector predictions are separate outputs, never inserted as ground truth.

Run `node tools/validate-video-manifest.mjs` for formal Ajv Draft2020-12 and additional semantic checks, and `node --test tools/video-manifest.test.mjs tools/video-scoring.test.mjs` for executable synthetic guards/scoring. Install pinned DataService development dependencies first. `score-video-traces.mjs` additionally verifies local media hashes under an explicit private asset root before publishing measurements. Exact commands, bounds, prediction contract, metrics and minimum still-unimplemented native export hook are in `video-scoring.md`. Hash checks do not decode actual frames or verify native orientation. Empty manifest reports accuracy unmeasured and accuracyGatePassed false.

ACTUAL Windows result: formal/semantic checks and empty scoring command report0clips/0observed/0hashedbytes; six synthetic tests pass including exact BigInt timestamps, held-out leakage, schema/identity/provenance, geometry/error/uncertainty/gap behavior, local hash/budget and outside-junction rejection. No native/video accuracy executed. Primary formats reviewed: [CMTime](https://developer.apple.com/documentation/coremedia/cmtime) and [JSON Schema2020-12](https://json-schema.org/draft/2020-12/json-schema-core).
